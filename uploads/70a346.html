01

最初に選ぶ3つのモード

答えが欲しいならChat、完成物が欲しいならWork、ソフト開発ならCodexです。

Chat

質問と会話を中心に、すぐ答えてもらう場所。

  • 相談・説明・文章作成
  • Web検索・画像・ファイル分析
  • 音声・Canvas・学習

Work

複数工程を任せ、使える完成物まで作る場所。

  • 文書・表計算・スライド・PDF
  • サイト・図解・画像・調査報告
  • 外部Apps、ブラウザ、長時間作業

Codex

コードと開発環境を扱う技術作業の場所。

  • コード作成・修正・テスト
  • Git、レビュー、ターミナル
  • ローカル・クラウド・IDE・CLI
やりたいこと選ぶ場所理由
質問に答えてほしいChat最短で会話を始められる
メール文を作りたいChat短い成果物は対話で十分
20ページのガイドをHTMLで作りたいWork調査・制作・ファイル保存・確認が必要
Excelを分析してグラフ付き報告書にしたいWork複数ファイルと複数工程をまとめて扱える
Webアプリの不具合を直したいCodexコード、コマンド、テスト、差分確認が必要
02

ChatGPTで作れる成果物

前の版で不足していた「何を完成ファイルとして作れるか」を、形式ごとに整理しました。

DOC

Word文書

報告書、企画書、契約書案、マニュアル、議事録。見出し・表・目次・画像も配置。

.docx / Google Docs
PDF

PDF

配布資料、申請ガイド、チェックリスト、印刷物、フォーム。レイアウトを確認して出力。

.pdf / fillable PDF
PPT

プレゼン資料

ウェビナー、営業資料、研修教材、提案書。編集できるスライドとして作成。

.pptx / Google Slides
XLS

表計算

リスト、集計表、料金表、比較表、試算表、ダッシュボード。数式・書式・グラフ対応。

.xlsx / .csv / Google Sheets
CSV

データファイル

CSV、TSV、JSON、XML、YAMLなどの整形、変換、分割、統合、クリーニング。

.csv / .tsv / .json / .xml
IMG

画像

写真風画像、イラスト、サムネイル、バナー、商品イメージ、背景透過素材、画像編集。

.png / .jpg / .webp
CHT

グラフ・チャート

棒、折れ線、円、散布図、ファネル、レーダーなど。数値と目的に合わせて作成。

HTML / PNG / spreadsheet chart
DGM

図解・フロー

業務フロー、組織図、関係図、タイムライン、手順図、比較図、インフォグラフィック。

HTML / Mermaid / SVG相当
HTM

HTML

ブログ、LP、ガイド、スライド、A4印刷物、編集ツール。CSS・JavaScriptを内蔵可能。

.html
WEB

Webサイト・Sites

公開できるランディングページ、ポータル、計算機、診断、ダッシュボード、業務ツール。

公開URL / source files
APP

アプリ・コード

Webアプリ、スクリプト、拡張機能、API連携、CLI、デスクトップ用コード。

source code / repository
NB

ノートブック

分析手順、実験、可視化、再実行できるデータ処理をコードと説明でまとめる。

.ipynb
TXT

文章・Markdown

メール、SNS、メルマガ、ブログ、FAQ、台本、プロンプト、仕様書、ナレッジ。

.txt / .md
ZIP

ファイル一式

HTML・画像・CSS、分割した表計算、複数資料などをまとめた配布用パッケージ。

.zip
REP

調査報告書

Web、添付資料、接続Appsを横断した引用付きの調査・比較・市場分析。

HTML / DOCX / PDF
TPL

テンプレート・フォーム

ヒアリングシート、チェックリスト、記入様式、評価表、編集可能なひな形。

DOCX / XLSX / HTML / PDF
Chatで文章を表示するだけと、ファイルを作ることは別です。 「Wordファイルとして」「編集できるPowerPointで」「画像を埋め込んだ1ファイルHTMLで」「完成後に表示を確認して」と、欲しい形式を明記してください。

05

Workで完成物まで任せる

Workは「回答」ではなく、調査・制作・確認を通じて使える成果物を作るモードです。

ローカル作業

デスクトップアプリで、PC上のファイル・フォルダ・対応アプリを使う作業。

  • PC内の資料を直接編集
  • ローカルのプレビューや確認
  • PCとアプリを開いておく必要あり

クラウド作業

Web・モバイル・デスクトップをまたいで、閉じた後も続けられる作業。

  • 長時間の調査・制作
  • 別端末から継続
  • ローカル専用ファイルは直接使えない

確認と承認

途中経過を見て方向修正し、重要な外部操作や変更を承認。

  • 進捗を確認
  • 追加情報へ回答
  • 送信・公開前に止める指定
添付した資料を根拠に、初心者向けの画像入りHTMLガイドを作成してください。 白・黒・ネイビーを使い、見出しと余白を大きくしすぎないでください。 文章、表、図解、チェックリストを入れ、スマホと印刷に対応してください。 完成後、目次リンク、画像、ボタン、印刷表示を確認し、HTMLファイルで渡してください。

CLIターミナル中心の開発コマンド、スクリプト、自動化、非対話実行

権限が広いほど便利ですが、事故の範囲も広がります。 読み取り、workspace内書き込み、ネット接続、PC操作、コマンド承認を分けて考えます。完成後は差分とテスト結果を確認してください。

07

設定で変えられること

プロフィールを押してSettingsを開きます。表示項目はプラン・端末・管理設定で変わります。

Account / Plan

アカウント、契約、請求、ワークスペース切替。

Personalization

性格、Characteristics、Custom Instructions、Memory。

Data Controls

モデル改善への利用、履歴、データ書き出し、Temporary Chat。

Apps

Google、Microsoft、Slack等の接続と権限。

Plugins / Skills

インストール済み機能、利用可否、作成・共有。

Notifications

Scheduled、長時間作業、確認事項の通知方法。

Voice

声の選択、字幕、マイク、音声データ設定。

Browser / Computer

Web閲覧、Chrome、PC・アプリ操作の接続と許可。

Keyboard Shortcuts

新しいチャット、検索、設定、音声入力などのキー。

Models

利用モデル、推論レベル、Work・Codexの初期値。

Archived chats

アーカイブした会話の確認と削除。

Workspace controls

管理者によるApps、Plugins、機能、権限、保持の設定。

MemoryとCustom Instructionsの違い
  • Custom Instructions：自分で書いた固定ルール。例「結論を先に」「行政書士向けに」。
  • Memory：会話から覚えた名前、好み、目標など。確認・削除・停止が可能。
  • Project instructions：その案件だけに効く指示。
  • Skill：特定業務を毎回同じ手順・形式で行う仕組み。
